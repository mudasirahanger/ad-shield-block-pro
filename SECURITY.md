# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private reporting:
**Security → Report a vulnerability** on this repository. Include steps to reproduce and the Chrome version.

You can expect an acknowledgement within a few days. Valid reports are fixed and credited (if you wish) in the release notes.

## Privacy promise

The extension makes no network requests of its own, collects no data, and runs no remote code. A change that breaks this promise is treated as a security bug.
