# Code of Conduct

We want this project to be welcoming to everyone.

**Expected:** be kind and respectful, give and accept constructive feedback gracefully, focus on what is best for the community and the project.

**Not acceptable:** harassment, insults, discriminatory language or jokes, personal attacks, publishing others' private information, trolling, or other conduct that would be inappropriate in a professional setting.

Maintainers may remove comments, commits, issues, or contributions that violate this code, and may ban contributors for repeated or severe violations.

To report a problem, open a private security advisory on the repository or contact the maintainer, Mudasir Ahanger, through the email on their GitHub profile.

This code is adapted from the ideas of the [Contributor Covenant](https://www.contributor-covenant.org/).
